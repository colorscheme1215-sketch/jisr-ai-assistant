プライバシー ポリシー（JISR AI Assistant）

運営者：JISR
最終更新日：2026年10月4日

1. 取得する情報

本ツールは、ユーザーが許可した範囲で、Google ドライブ、ドキュメント、スプレッドシート、スライドのファイルとその内容にアクセスします。

2. 利用目的

取得した情報は、ユーザーの指示に従って、ファイルの検索、閲覧、作成、編集を行うためだけに使います。

3. 保存場所

認証の情報（アクセストークン）は、ユーザー自身のコンピュータの中だけに保存されます。運営者のサーバーには送りません。

4. 第三者への提供

取得した情報を販売したり、広告に使ったりすることはありません。ただし、ユーザーの指示を処理するために、ユーザーが使っている AI アシスタント（Anthropic 社の Claude）にファイルの内容が送られる場合があります。

5. Google API の利用について

本ツールが Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

6. アクセスの取り消し

https://myaccount.google.com/permissions から、いつでもアクセスを取り消せます。
